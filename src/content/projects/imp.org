A small Rust core handles buffers, rendering and parsing. Every key, command and mode is Scheme ([[https://github.com/mattwparas/steel][Steel]]) that you can redefine while it runs. imp is in alpha, but I use it day to day, and it shows I'm comfortable working below the web stack.
